1. HIGH-LEVEL ARCHITECTURE & SYSTEM DESIGN
================================================================================
To design and build NovaMart, you must understand multi-tier client-server
architecture and decoupling frontend and backend services:

* Client-Server Architecture:
  - Frontend (Client): Single-Page Application (SPA) running on Port 5173.
  - Backend (Server): Stateless REST API running on Port 8080.
  - Database: Relational persistence layer on Port 3306 (MySQL) or in-memory (H2).

* Unified Multi-Role Portals in a Single SPA:
  - Customer Storefront: Product browsing, cart, checkout, order tracking.
  - Admin Operations Portal: Product catalog, inventory, zones, order dispatch.
  - Delivery Partner Portal: Assigned shipments, route delivery, OTP verification.

* Separation of Concerns:
  - Controllers: Handle HTTP requests, input validation, and route responses.
  - Services: Contain all business logic, transaction boundaries, and calculations.
  - Repositories: Direct database interaction using Object-Relational Mapping (ORM).
  - Entities/DTOs: Data structures representing database tables and network payloads.

2. FRONTEND CONCEPTS (React 19, JavaScript ES6+, Modern Web)
================================================================================
To build the user interface, routing, and interactive client workflows:

A. Modern JavaScript (ES6+ & Beyond):
   - ES Modules: import/export syntax for modular code organization.
   - Asynchronous Programming: Promises, async/await syntax, and error handling.
   - Array & Object Operations: map(), filter(), reduce(), find(), spread/rest operators.
   - Destructuring: Object and array destructuring for clean props and state access.
   - Storage APIs: LocalStorage and SessionStorage for client-side persistence.

B. React 19 Core Fundamentals:
   - Component-Driven Architecture: Functional components and reusable UI widgets.
   - JSX Syntax: Writing declarative HTML-like structures inside JavaScript.
   - Virtual DOM & Reconciliation: How React updates the UI efficiently.
   - Props & State: Unidirectional data flow and immutable state updates.

C. Essential React Hooks:
   - useState: Managing local component states (inputs, modals, toggle states).
   - useEffect: Managing side effects (API calls, subscriptions, event listeners).
   - useContext: Subscribing to React Contexts without prop drilling.
   - useMemo: Caching expensive calculations (e.g., cart totals, filtered catalog).
   - useCallback: Memoizing callback functions to prevent unnecessary child re-renders.
   - useRef: Referencing mutable values or direct DOM elements without re-rendering.

D. Global State Management (React Context API):
   - AuthContext: User login state, JWT token storage, user roles, and logout logic.
   - CartContext: Add/remove items, update quantities, calculate subtotals & taxes.
   - LocationContext: Selected delivery PIN code, address, and serviceability state.
   - WishlistContext: Managing saved-for-later items.

E. Client-Side Routing (React Router DOM v7):
   - BrowserRouter, Routes, Route, and Outlet for nested layouts.
   - Dynamic Route Parameters: useParams() (e.g., /product/:id, /order/:id).
   - Programmatic Navigation: useNavigate() and useLocation().
   - Protected Routes & Route Guards: Custom components checking authentication
     and authorization roles before allowing access to /admin or /delivery-partner.

F. API Communication (Axios):
   - Axios Client Instance: Pre-configured with base URL (http://localhost:8080/api).
   - Request Interceptors: Automatically attaching the Bearer JWT token to headers.
   - Response Interceptors: Centralized error handling (redirecting on 401/403).
   - Async state handling: Managing loading spinners, success messages, and error banners.

G. Modern UI/UX & Styling:
   - CSS3 Layouts: Flexbox and CSS Grid for responsive multi-column layouts.
   - CSS Variables (Design Tokens): Harmonious color palettes, shadows, spacing.
   - Responsive Design: Media queries for desktop, tablet, and mobile views.
   - Iconography: Lucide-React SVG icons for modern UI controls.
   - Micro-Interactions: Confetti celebrations (canvas-confetti), animated badges.

3. BACKEND CONCEPTS (Java 21 & Spring Boot 3.3+)
================================================================================
To build the robust, scalable server-side REST API:

A. Java 21 & Object-Oriented Programming (OOP):
   - Core OOP Principles: Encapsulation, Abstraction, Inheritance, and Polymorphism.
   - Java Collections Framework: List, Set, Map, ArrayList, HashMap.
   - Streams API & Lambdas: Functional filtering, mapping, and aggregating data.
   - Optional<T>: Avoiding NullPointerExceptions in service and repository queries.
   - Exception Handling: Checked vs unchecked exceptions, custom domain exceptions.
   - Modern Java Features: Records (immutable data carriers), enhanced switch statements.

B. Spring Boot Framework Fundamentals:
   - Inversion of Control (IoC) & Dependency Injection (DI): Managing object lifecycles.
   - Core Annotations:
     * @SpringBootApplication (Entry point)
     * @RestController & @RequestMapping (REST controllers)
     * @Service (Business logic layer)
     * @Repository (Data access layer)
     * @Component & @Configuration (Custom Spring beans)
     * @Autowired / Constructor Injection (Wiring dependencies)
   - Configuration Management: application.properties / application.yml.

C. RESTful Web Services & API Design:
   - HTTP Methods: GET (read), POST (create), PUT (update), DELETE (remove).
   - HTTP Status Codes: 200 OK, 201 Created, 400 Bad Request, 401 Unauthorized,
     403 Forbidden, 404 Not Found, 409 Conflict, 500 Internal Server Error.
   - Parameter Binding: @PathVariable, @RequestParam, @RequestBody, @RequestHeader.
   - Structured Responses: ResponseEntity<T> wrapping custom API response envelopes.

D. DTO (Data Transfer Object) Pattern:
   - Separation of database models (Entities) from network contracts (DTOs).
   - Request DTOs (e.g., LoginRequest, RegisterRequest, OrderCreateRequest).
   - Response DTOs (e.g., UserSummaryResponse, OrderDetailsResponse).
   - Mapping between DTOs and Entities to prevent leaking sensitive database columns.

E. Input Validation & Global Exception Handling:
   - Jakarta Validation: @NotNull, @NotBlank, @Email, @Size, @Min, @Pattern.
   - @Valid annotation on incoming controller request bodies.
   - @RestControllerAdvice & @ExceptionHandler: Intercepting exceptions across the
     entire application and returning clean, standardized error responses.

4. DATABASE & ORM CONCEPTS (Spring Data JPA, Hibernate, MySQL, H2)
================================================================================
To design database schemas, relationships, and performant data queries:

A. Relational Database Concepts (RDBMS):
   - Relational modeling: Tables, primary keys, foreign keys, unique constraints.
   - Normalization: 1NF, 2NF, 3NF to avoid data redundancy and anomalies.
   - Indexing: Creating indexes on high-frequency search fields (e.g., email, pincode).

B. Spring Data JPA & Hibernate ORM:
   - Entity Mapping: @Entity, @Table, @Id, @GeneratedValue, @Column, @Enumerated.
   - Entity Relationships:
     * @ManyToOne: Order -> User (many orders belong to one user)
     * @OneToMany: Order -> OrderItems (one order has many line items)
     * @ManyToOne: Product -> Category
     * @ManyToMany: DeliveryPartner <-> DeliveryZone (serviceable areas)
   - Cascading & Lifecycle: CascadeType.ALL, orphanRemoval = true.
   - Fetching Strategies: FetchType.LAZY vs FetchType.EAGER, and preventing N+1 queries.

C. Repository Layer & Query Construction:
   - JpaRepository interface: Built-in CRUD, sorting, and pagination methods.
   - Query Derivation: Writing repository methods parsed automatically by Spring Data
     (e.g., findByEmail, findByPincodeAndIsActiveTrue, findAllByOrderByCreatedAtDesc).
   - Custom Queries: Using @Query with JPQL (Java Persistence Query Language) or Native SQL.
   - Pagination & Sorting: Pageable, PageRequest, Sort for handling large product lists.

D. Transaction Management:
   - @Transactional annotation: Ensuring ACID properties.
   - Atomic multi-step operations: Creating an order, decrementing product stock,
     recording payment, and clearing cart in a single atomic database transaction.

E. Database Engines:
   - MySQL: Production-grade relational database with persistent storage.
   - H2 Database: In-memory relational database for zero-setup local development.
   - Seed Data: Automated data seeding on startup using CommandLineRunner / DataInitializer.

5. SECURITY, AUTHENTICATION & ROLE-BASED ACCESS CONTROL (RBAC)
================================================================================
To protect endpoints, user data, and implement secure multi-role access:

A. Stateless Authentication with JWT (JSON Web Tokens):
   - JWT Anatomy: Header (algorithm), Payload (claims/username/roles), Signature.
   - JJWT Library (io.jsonwebtoken): Generating, signing, and parsing tokens.
   - Token Lifecycle: Setting token expiration and verifying digital signatures.

B. Spring Security 6 Architecture:
   - SecurityFilterChain: Defining security filters and HTTP authorization rules.
   - Disabling CSRF: Appropriate for stateless REST APIs using Bearer tokens.
   - Session Management: SessionCreationPolicy.STATELESS (no HTTP sessions on server).
   - Custom JWT Filter: OncePerRequestFilter parsing Authorization: Bearer <token>,
     validating it, and populating the Spring SecurityContextHolder.

C. Role-Based Access Control (RBAC):
   - User Roles:
     * ROLE_CUSTOMER: Browse, place orders, view personal order history.
     * ROLE_ADMIN: Manage products, inventory, users, delivery zones, reports.
     * ROLE_DELIVERY_PARTNER: View assigned orders, update shipment status, verify OTP.
   - Declarative Security:
     * URL Matchers: .requestMatchers("/api/admin/**").hasRole("ADMIN")
     * Method Security: @PreAuthorize("hasRole('DELIVERY_PARTNER')")

D. Password Security:
   - Cryptographic Hashing: BCryptPasswordEncoder with salt.
   - Preventing plain-text password storage in database backups and logs.

E. CORS (Cross-Origin Resource Sharing):
   - Configuring allowed origins (http://localhost:5173), methods (GET, POST, etc.),
     and headers (Authorization, Content-Type) so the browser allows API calls.

6. ADVANCED DOMAIN LOGIC & E-COMMERCE ALGORITHMS
================================================================================
These are the business algorithms that make NovaMart a realistic B2C platform:

A. Hyperlocal Area / PIN-Code Delivery Assignment Engine:
   - Concept: In B2C commerce, logistics are constrained by geographical zones.
   - Zone Serviceability Check: Matching the customer's delivery PIN code against
     active serviceable zones in the database before order placement.
   - Automated Partner Dispatch: When an order is placed in PIN code X, find active
     delivery partners assigned to zone X and dispatch based on workload/availability.

B. Secure One-Time Password (OTP) Delivery Verification:
   - Secure generation of a 6-digit numeric OTP when shipment is out for delivery.
   - Storing the OTP hash/code securely in the database tied to the order.
   - Physical handoff workflow: Delivery partner collects OTP from the customer,
     submits it via the Delivery Partner Portal -> Backend validates OTP ->
     Order status transitions to DELIVERED.

C. Order State Machine:
   - Finite State transitions:
     [PENDING] -> [CONFIRMED] -> [ASSIGNED] -> [OUT_FOR_DELIVERY] -> [DELIVERED]
                                \
                                 -> [CANCELLED]
   - Transition validation: Ensuring an order cannot jump from PENDING to DELIVERED
     or be cancelled after being completed.

D. Inventory & Pricing Calculations:
   - Real-time stock decrement upon checkout to prevent race conditions (overselling).
   - Automated stock restoration if an order is cancelled.
   - Pricing Engine: Item price * quantity, applying coupon discount percentages,
     calculating delivery fees based on order threshold, and adding GST/taxes.

7. DEVOPS, AUTOMATION, SCRIPTS & BUILD TOOLS
================================================================================
To run, orchestrate, build, and maintain this full-stack project smoothly:

A. Build Systems:
   - Vite: Fast module bundler, development server, and production build tool.
   - Apache Maven: Java project build tool, dependency management (pom.xml),
     packaging into executable JARs.

B. Monorepo Orchestration & Scripts:
   - Concurrently: Running Spring Boot backend, Vite frontend, and backup watcher
     together in a single terminal with colored prefixes.
   - Windows Batch (.bat) Scripts: 1-click launchers for development:
     * start-all.bat: Launches backend, frontend, and watcher in dedicated consoles.
     * start-backend.bat & start-frontend.bat: Starts services independently.
     * clean-build.bat: Verifies compilation and clean builds.

C. Database Reliability & Auto-Backup Engineering:
   - Node.js Scripting: Running mysqldump automation (backup-db.js) and restore (restore-db.js).
   - Automated Watcher: auto-backup-watcher.js for continuous snapshotting of code
     and database changes.

D. Version Control & Clean Code:
   - Git workflow: Branching, commits, and proper .gitignore setup for multi-language
     codebases (ignoring target/, node_modules/, .env, backups/).
   - Enterprise documentation: Writing architecture blueprints and REST API docs.

8. STEP-BY-STEP RECOMMENDED LEARNING ROADMAP
================================================================================
If you are learning to build a project like NovaMart from scratch, follow this
structured path:

PHASE 1: Core Fundamentals
  1. Master modern JavaScript (ES6+): Promises, async/await, array methods.
  2. Master modern Java (Java 17/21): OOP, Collections, Streams, Exceptions.
  3. Master Relational Databases (SQL): Queries, Joins, Primary/Foreign keys.

PHASE 2: Backend Development (Spring Boot)
  4. Learn Spring Boot basics: Dependency Injection, @RestController, @Service.
  5. Build CRUD REST APIs with Spring Data JPA and Hibernate.
  6. Learn DTOs, Jakarta Validation, and @RestControllerAdvice exception handling.

PHASE 3: Security & Identity Management
  7. Learn Spring Security 6 architecture and SecurityFilterChain.
  8. Implement password encryption with BCrypt.
  9. Implement stateless authentication with JWT tokens (login, register, token filter).
  10. Add Role-Based Access Control (Admin, Customer, Delivery Partner).

PHASE 4: Frontend Development (React)
  11. Learn React fundamentals: JSX, Components, Props, useState, useEffect.
  12. Learn React Router DOM: Client-side routing, protected routes for roles.
  13. Master Global State using React Context API (Auth, Cart, Location).
  14. Connect React to Spring Boot using Axios and configure JWT interceptors.

PHASE 5: Advanced Business Features
  15. Build the E-Commerce Storefront: Catalog, Search, Filters, Cart, Checkout.
  16. Build the Hyperlocal Delivery Engine: PIN code validation & partner dispatch.
  17. Build the OTP Verification System for delivery completion.
  18. Build the Admin Operations Dashboard: Inventory, Orders, Zone Management.

PHASE 6: Tooling, Polish & Production
  19. Implement responsive CSS styling, toast notifications, and UI animations.
  20. Create unified startup scripts (concurrently, .bat) and backup scripts.
